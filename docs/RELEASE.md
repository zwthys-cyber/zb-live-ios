面向 iOS 17.0 及以上、已安装 TrollStore 的设备。

下载 `Live-iOS17-TrollStore.ipa`，在 iPhone「文件」中打开分享菜单，选择 TrollStore 安装。不需要 Apple 开发者证书。

已实现：平台网页入口、网页内观看与登录、当前页面收藏、HLS / MP4 等兼容视频直链播放、观看记录、M3U / JSON / 文本频道导入、订阅合并刷新、系统画中画与投屏。

平台入口是原 APK 中出现的平台主页，在内置 WebKit 浏览器打开。原应用私有房间列表、账户体系、专有隧道、付费内容接口尚未接通；它们不包含在本次移植范围中。网页、登录、地区限制与单个视频源的可用性仍取决于平台与网络。

CI 会运行解析器、资料持久化及界面测试，然后编译 ARM64 真机应用，验证 iOS 17.0 最低版本并进行无需证书的 ad-hoc 签名。尚未在用户的 iOS 17.0 真机上验证。
