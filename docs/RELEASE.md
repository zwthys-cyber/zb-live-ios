面向 iOS 17.0 及以上、已安装 TrollStore 的设备。

下载 `Live-iOS17-TrollStore.ipa`，在 iPhone「文件」中打开分享菜单，选择 TrollStore 安装。

此版本接入原服务的平台、房间和播放接口，恢复签名、设备标识、访问票据、直播会话、RSA 密钥交换及 AES 响应解密。直播首页可直接选择平台与房间。收藏房间每次打开都会更新播放地址。生产接口已返回 27 个平台，并实际取回 HLS 播放清单和视频分片。

保留网页、直链、收藏、历史、频道导入、订阅、画中画及 AirPlay。

原账户体系、Android 专用隧道、专有 RTC / 特殊加密播放组件尚未移植；部分房间可能没有兼容线路。当前播放验证只覆盖实际检查的 HLS 线路，不代表全部平台均可播放。未在用户 iOS 17.0 真机实测。
